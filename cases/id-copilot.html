ID COPILOT

AI interior design workflow prototype

What it is

An exploration of how AI could reduce the administrative work surrounding interior design while preserving the part designers actually value: designing. ID Copilot covers agentic AI, LLM workflows, space planning and quotation automation.

The problem

Interior design carries a long tail of administration around the creative work — briefs, floor-plan analysis, measurements, quotations. I wanted to see how far an AI copilot could take that surrounding work, screen by screen.

Approach

The prototype is built as a wireframed flow: the opening screen captures the home, lifestyle and design preferences, and creates the identity that every later screen’s data attaches to. Ideas become a personalised design concept through LLM workflows — including floor-plan analysis, which I moved onto the Anthropic API during development while debugging the agent’s connection through to a deployed backend on Vercel.

Tech

  • Static front-end prototype with per-screen wireframe notes marking how data attaches across the flow
  • LLM workflows behind a deployed API (Vercel), floor-plan analysis via the Anthropic API
