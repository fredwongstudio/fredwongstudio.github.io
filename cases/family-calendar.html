FAMILY CALENDAR

A shared family schedule, kept simple

What it is

A personal family calendar application for organising and managing shared family schedules. Not a product — a tool for my own household, built the way I want it to work.

The problem

A shared family schedule has simple, stubborn requirements: it has to work on a phone held in one hand, mark school holidays, allow all-day entries, and stay readable when an event description is long. The repository’s iteration history shows exactly where the difficulty was — mobile row views, mobile time pickers, school-holiday shading, and grid columns drifting under long event text.

Approach

One self-contained page, refined through many small passes: a responsive calendar grid that reflows into a row-based view on mobile, all-day entries in the time picker, school-holiday shading on the calendar, and layout fixes as real use exposed them — long event text drifting the grid columns, mobile pickers, type sizes.

Tech

  • A single HTML/CSS/JS file — no dependencies, no account, no server
  • Entries persist in browser localStorage
