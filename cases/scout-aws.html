SCOUT AWS

Agentic commerce, re-architected on AWS

What it is

An experimental, AWS-focused evolution of the original SCOUT agentic commerce prototype. Its purpose is to explore how SCOUT’s agentic travel experience can be architected using AWS infrastructure while retaining the freedom to experiment with different AI models and providers.

Approach

The README sets the discipline: the current V0 state preserves the inherited SCOUT application behaviour before AWS infrastructure is introduced — the baseline is committed and labelled (V0 pre-AWS, then V0.1 to distinguish the fork) so the evolution can be measured against the original.

The structure separates the customer-facing application (app/) from backend orchestration (server/), with supporting utilities in scripts/. Payment and booking execution remain simulated — this is a prototype, not a production booking system.

Tech

  • Frontend (Vite) and backend run as separate processes; the dev server proxies /api to the backend on port 3000
  • Local configuration via .env (kept out of the repository)
