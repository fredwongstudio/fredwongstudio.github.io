ZERO

AI hotel operator prototype — dial 0, just ask

What it is

A working AI hotel operator prototype that lets hotel guests press 0 and speak naturally to an AI operator — an exploration of what guest service could become when an AI can understand, respond and coordinate service requests.

The problem

Pressing 0 for the operator is the oldest interface in hotels. ZERO asks what happens when that call is answered by an AI operator that can hold a natural conversation, clarify details like quantities, and act on them.

Approach

The guest presses 0; ElevenLabs owns the live call audio over WebRTC, with a short-lived conversation token obtained server-side so credentials never reach the browser. The agent is given one client tool, createServiceRequest, with a strict parameter contract (room, request type, item, quantity, department); the app validates every parameter, returns a simulated created result, and shows a post-call summary.

I kept the prototype deliberately honest about what it is: payment and dispatch are simulated, state lives only in memory for the duration of one call, and there is no database, login or real housekeeping integration. Without configured credentials the interface says so clearly rather than pretending the call worked.

Tech & verification

  • Next.js / React / TypeScript / Tailwind; ElevenLabs conversational agent with a client-tool contract
  • Unit checks (validated requests, rejected invalid quantities, conservative Wi-Fi resolution, mocked token route) and a browser suite across 375–1440px covering keyboard activation, touch targets, mute, error states and microphone denial
  • Live acceptance with a real configured agent remains open — the README lists the checks still required
