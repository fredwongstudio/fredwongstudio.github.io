DIGITAL WORKFLOW TOOLS

Practical workflow tools for renovation work

What it is

A collection of practical tools exploring how repetitive, fragmented and manual work can be made dramatically simpler. Each one replaces a spreadsheet-and-repetition step in renovation workflow with a single focused web tool.

The tools

  • Floor Plan Take-off — an interactive digital take-off: upload a floor plan, set the scale, drag and resize area boxes over each room; length, width and sqft fill in automatically. Built with Claude to simplify renovation workflows.
  • Area Calculator — an area measurement calculator that collapses 45–55 renovation calculations into a single workflow; measurements entered in mm, consistent conversion (304.8 mm = 1 ft) built in.
  • Quote Builder — a quotation system that turns a 13,000+ item spreadsheet catalogue into a structured digital workflow: search, add items to a quote, done.

Where they came from

These grew directly out of the friction I hit while doing 3D visualisation work by hand — measurements, take-offs, documentation and quotations. Each tool is deliberately small, self-contained and usable in the browser.
